# 🏛️ 열린소통 익명신문고 (Complaint Board)

> **신뢰할 수 있는 공공기관 행정 서식과 자유로운 익명 커뮤니티의 장점을 결합한 웹 기반 익명 민원 포털 시스템**

---

## 📌 프로젝트 소개

본 프로젝트는 시민이나 구성원이 신원 노출이나 불이익 걱정 없이 자유롭게 의견과 민원을 개진할 수 있도록 구축된 **익명 보장형 민원 게시판 시스템**입니다.  
불필요한 팝업 모달 없이 단일 페이지 애플리케이션(SPA) 내부 라우팅을 통해 정식 페이지(`#/new`, `#/detail`, `#/admin/login`) 간 전환을 지원하며, Web Crypto API(SHA-256) 단방향 암호화를 통해 비밀글 및 수정/삭제 권한을 안전하게 보호합니다.

---

## ✨ 핵심 기능 (Core Features)

### 1. 비회원 익명 고정 및 회원 로그인 시스템
- **우측 상단 로그인 영역**: '관리자 로그인'과 나란히 '회원 로그인' 창구 제공
- **비회원 익명 고정**: 회원으로 로그인하지 않은 경우 '작성자 이름' 칸이 자동으로 숨겨지며 '익명'으로 안전하게 고정 등록됩니다.
- **안전한 비밀번호 체계**: 비회원이라도 본인 확인 및 글 수정/삭제, 비밀글 열람을 위해 4~8자리 영문/숫자 비밀번호(SHA-256 단방향 암호화)는 필수로 유지됩니다. (특수문자, 공백 불가)
- **회원 로그인 시**: 작성자 이름(실명 또는 닉네임)이 노출되며, 원하는 경우 체크박스를 통해 '익명'으로도 자유롭게 전환할 수 있습니다.

### 2. 비밀글(비공개) 보호 시스템
- **비밀글 설정**: 작성 시 `비밀글로 설정하기`를 체크하면 목록에서 내용이 마스킹 처리되어 일반 사용자에게 노출되지 않습니다.
- **인라인 본인 인증**: 작성자 본인은 본문 영역 내의 인증창에서 영문/숫자 4~8자리 비밀번호를 입력하여 내용을 열람할 수 있습니다.

### 3. 단일 페이지 애플리케이션 (SPA) 내부 라우팅
- 팝업 오버레이(모달) 없이 URL 해시 기반으로 정식 페이지가 매끄럽게 전환됩니다:
  - `#/list`: 전체 민원 목록 및 필터링 검색
  - `#/new`: 새 민원 신청서 작성 페이지 (비회원 시 작성자명 숨김 및 익명 고정)
  - `#/detail?id=...`: 민원 상세 열람 및 답변 확인
  - `#/edit?id=...`: 민원 수정 페이지
  - `#/user/login`: 신문고 회원 로그인 및 회원가입 페이지 (좌측 로그인 / 우측 회원가입 2분할 패널)
  - `#/user/menu`: 회원 메뉴 및 닉네임 설정 페이지 (좌측 세로 메뉴 탭 / 우측 닉네임 변경 폼)
  - `#/admin/login`: 행정 관리자 전용 인증 로그인 페이지
  - `#/verify?id=...`: 수정/삭제 시 본인 인증 페이지

### 4. 행정 관리자 권한 및 공식 답변 기능
- **관리자 전용 로그인**: 전용 보안 창구를 통해 관리자 세션 진입
- **모든 비밀글 무제한 열람**: 관리자 모드 활성화 시 비밀번호 없이 모든 비밀글의 본문 열람 가능
- **공식 답변 등록**: 게시글별 공식 답변 작성/수정/삭제 지원 (답변 등록 시 민원 처리상태가 자동으로 `답변완료`로 전환)
- **처리상태 관리**: `접수대기` ➔ `처리중` ➔ `답변완료` 단계별 상태 변경

### 5. 검색 및 카테고리 필터
- 상단 갤러리풍 통합 검색창 및 게시판 내부 키워드 검색
- 상단 GNB '전체보기' 클릭 시 전체 카테고리 바로가기 드롭다운 패널 제공
- 네비게이션 바는 간결한 텍스트(`시설/환경`, `건의사항`, `서비스 불만`, `기타`)로 표시되며, 목록/필터에서는 번호순 정렬 연동
- `익명글`, `비밀글`, `답변완료` 원클릭 퀵 필터링

## 📂 프로젝트 구조

```
complaint-board/
├── index.html        # 시맨틱 구조의 메인 HTML (단일 페이지 다중 뷰 구성)
├── styles.css        # 공공기관 신문고 + 익명 커뮤니티 하이브리드 CSS
├── app.js            # 핵심 비즈니스 로직, SHA-256 암호화, SPA HashRouter
├── server.ps1        # 간이 로컬 정적 웹 서버 스크립트 (PowerShell)
├── .gitignore        # Git 버전 관리 제외 파일 정의
└── README.md         # 프로젝트 안내 및 사용 가이드
```

## 🛠️ 기술 스택

- **Frontend**: HTML5, Modern CSS3 (Flexbox/Grid, Responsive), Vanilla JavaScript (ES6+)
- **Security**: Web Crypto API (`crypto.subtle.digest` SHA-256)
- **Data Persistence**: LocalStorage API, SessionStorage API (무설치 브라우저 데이터 영구 저장)

## 🚀 시작하기

### 로컬 실행 방법
별도의 패키지 설치 없이 웹 브라우저에서 바로 실행할 수 있습니다:

1. **브라우저 직접 실행**: `index.html` 파일을 더블 클릭하여 크롬, 엣지 등 브라우저에서 바로 엽니다.
2. **로컬 서버 실행 (선택)**:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
   실행 시 `http://localhost:8080/#/list`로 자동 접속됩니다.

## 깃허브(GitHub) 원격 저장소 푸시 가이드

새로운 깃허브 리포지토리에 푸시할 때 아래 순서대로 터미널에서 실행하시면 됩니다:

```bash
# 1. 변경사항 스테이징
git add .

# 2. 첫 번째 커밋 생성
git commit -m "feat: 익명 민원 게시판 시스템 구축 (익명/비밀글, SHA-256 암호화, 관리자 답변 기능)"

# 3. 메인 브랜치 설정
git branch -M main

# 4. GitHub 원격 저장소 연결 (본인의 GitHub 리포지토리 URL로 변경)
git remote add origin https://github.com/사용자아이디/리포지토리이름.git

# 5. 원격 저장소로 푸시
git push -u origin main
```
